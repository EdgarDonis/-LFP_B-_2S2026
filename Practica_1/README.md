## Descripción
Este proyecto es un motor de validación desarrollado en Python utilizando Programación Orientada a Objetos. El sistema procesa archivos de texto delimitados por comas (`.lfp`) para validar intentos de Sudoku mediante el análisis de matrices de 9x9, comprobando filas, columnas y subcuadrículas de 3x3.

## Requisitos
* Python 3.x
* No requiere librerías externas.

## Instrucciones de Ejecución
1. Clonar el repositorio.
2. Asegurarse de tener los archivos `sudokus.lfp`, `jugadores.lfp` e `intentos.lfp` en el mismo directorio.
3. Ejecutar en consola: `python main.py`
4. Seguir las instrucciones del menú interactivo para cargar datos, calificar y generar reportes en formato HTML.
